- **Date**: Most recent deepdive pass date for that stock

## Notes

- **Identification method (revised)**: A stock counts as "deepdived" if its queue entry has `deepdive_pass >= 1` (equivalently, a non-empty `history` array), sourced from `data/deepdive-queue.json`. This reflects the full deepdive history across all passes, regardless of current pool membership. The previous version of this document used `deepdive_status == "done"`, which only flags entries finished in the *current* rotation and undercounted the true total (69 vs. the actual 170).
- **Confidence Score caveat**: This is NOT the same as `conviction_score` (own-conviction + trusted-lift). It is Confluence-100's separate blended confidence percentage, only available for stocks currently ranked in the top-100. A stock that has dropped out of Confluence-100 (e.g. due to technical deterioration or a name entering it) shows "—" here even though it retains a Master Score.
- **Four Box Score**: Missing for E2E Networks Ltd (data gap in that stock's deepdive record).
- **Automatic Updates**: Regenerate this document after each deepdive-top100 job completion by re-running the extraction against `data/deepdive-queue.json` (filter `deepdive_pass >= 1`) and `data/confluence100.json` (cross-reference by slug for the Confidence Score / In Confluence-100 columns).
