How the ranking and confidence % are built

Universe. 616 stocks have been deepdived by the ValuePickr open-screen pipeline. 164 clear the bar this list draws from: thesis_fit is 10x-in-2-3-years or 100x-in-10-years, and red_flag_tier is clear (HIGH CAUTION / AVOID / EXCLUDE names are hard-dropped, not sized down). This is a different, larger universe than the live Rs 1L portfolio — only a handful of names overlap (marked HOLD).

Master score is this pipeline's own composite — 0.25×conviction + 0.25×quality + 0.20×expectation-gap + 0.15×consistency + 0.15×asymmetry, renormalized over whichever components exist for that stock (see MASTER_SCORE_METHODOLOGY.md). Coverage is thin almost everywhere: only 12 of the eligible names have 4-5 of those components computed — the rest are still mostly riding on conviction_score alone, with the deepdive's own qualitative four_box read (tailwind / TAM / moat / valuation, scored 0-5) blended in to partly compensate, weighted more heavily the thinner the coverage.

Technical overlay. For each of the top candidates a live weekly chart was pulled (Yahoo Finance, 3-year history) and a 30-week EMA computed — the same discipline the live portfolio runs on. Sitting tight above the line (≤15%) or crossing it in the last 3 weeks adds to confidence; sitting below it cuts hard (a stock can be fundamentally excellent and still fail the entry-timing filter); very extended (>45% above) is discounted too, since that's poor risk-reward to buy into, not a red flag on the business. Names that couldn't be ticker-matched automatically carry a small penalty for that data gap rather than a real technical read.

Confidence % is a model output, not a probability of return. Treat ≥70 as "worth a full-position look," 50-69 as "real but thin, verify before sizing," and <50 as "on the radar, not yet actionable." No stock here was sourced by open-ended web search — every name already existed in the ValuePickr deepdive database. Refreshed weekly as a side job of vpscreen-rerank.
